# AI Usage

I used ChatGPT as an AI coding assistant while completing this exercise.

## Part 1 — Code Review

I first reviewed the existing application and identified the main issues around organisation access, permissions, pagination, filtering, and authentication.

AI was mainly used to:

* validate some of my findings
* discuss the severity and impact of the issues
* help review possible fixes
* check that the changes stayed within the existing architecture
* help with testing and edge cases

I selected the five issues to fix and manually reviewed and tested the changes before including them.

## Part 2 — SLA Breach Tracking

I used significantly more AI assistance for the SLA feature due to the available time.

AI helped with:

* understanding the SLA requirements
* deciding how to handle ambiguous cases such as resolved and closed tickets
* designing the SLA calculation
* implementing the backend SLA fields
* working on SLA filtering
* adding the SLA indicators to the React UI
* debugging and testing the implementation
* documenting the SLA decisions

Where AI-generated or AI-suggested code was used, I reviewed it before adding it to the project and made sure I understood how it worked and how it fitted into the existing codebase.

I also manually ran and tested the application during the implementation rather than relying only on generated code.

## Responsibility

AI was used as a development assistant rather than as a replacement for reviewing the codebase.

I remain responsible for the final implementation, the decisions made in the exercise, and being able to explain the code that was submitted.
